# ADRs

Decisões de arquitetura, uma por arquivo, numeradas em sequência (`NNNN-titulo.md`).
Formato: Estado, Data, Contexto, Decisão, Consequências. Uma decisão substituída não é apagada:
muda o estado para "substituído por NNNN".
