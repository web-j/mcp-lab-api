Como conectar o MCP Lab

Use o endereço abaixo no app de IA que você já usa. Na primeira conexão ele abre a página do MCP Lab para você entrar (ou criar a conta) e autorizar.

https://mcp.agateo.com.br/mcp
Peça para a sua IA conectar Copie e cole na conversa do Claude, ChatGPT, Grok ou Cursor. Ela lê as instruções e faz a conexão ou diz onde clicar.
Quero usar o MCP Lab da Agateo aqui. Leia as instruções em https://auth.agateo.com.br/llms.txt e conecte o servidor MCP https://mcp.agateo.com.br/mcp para mim. Se você não conseguir adicionar o conector sozinho, me diga exatamente onde clicar neste app.

Primeira conexão

  1. 01
    Adicione o endereço no seu appVeja abaixo onde fica a opção em cada um.
  2. 02
    Entre ou crie sua contaO app abre auth.agateo.com.br. Na conta nova, confirme o e-mail pelo link que chega na sua caixa de entrada, abrindo no mesmo navegador.
  3. 03
    Clique em PermitirA tela mostra qual app está pedindo acesso. Depois disso você volta para o app, já conectado.
  4. 04
    Peça na conversaPor exemplo: “anota que estou planejando o orçamento de dezembro”. Depois, em outro app: “onde eu parei?”.

Onde adicionar em cada app

Os menus mudam com frequência. Se não achar, procure por “conector”, “MCP” ou “app personalizado” nas configurações.

Claude (claude.ai e app desktop)
Configurações → Conectores → Adicionar conector personalizado → cole o endereço.
ChatGPT
Abra chatgpt.com/plugins → Add → Create MCP App → cole o endereço e escolha autenticação OAuth. A disponibilidade depende do plano.
Grok
Abra grok.com/connectors → New Connector → Custom → cole o endereço e faça o login quando pedir.
Cursor
Settings → MCP → Add new MCP server (tipo HTTP), ou no arquivo ~/.cursor/mcp.json: 
{
  "mcpServers": {
    "agateo": { "url": "https://mcp.agateo.com.br/mcp" }
  }
}
Claude Code
claude mcp add --transport http agateo https://mcp.agateo.com.br/mcp
Depois rode /mcp dentro do Claude Code e escolha agateo para fazer o login.
VS Code (Copilot)
No arquivo .vscode/mcp.json: 
{
  "servers": {
    "agateo": { "type": "http", "url": "https://mcp.agateo.com.br/mcp" }
  }
}
Outros apps
Qualquer app compatível com servidores MCP remotos (Streamable HTTP + OAuth) funciona com o mesmo endereço.

Para assistentes de IA e agentes

Se você é uma IA configurando esta conexão para alguém, use estes dados:

Endpoint MCP
https://mcp.agateo.com.br/mcp
Transporte
Streamable HTTP (POST JSON-RPC; servidor sem sessão)
Autenticação
OAuth 2.1 com PKCE. Sem token, o servidor responde 401 com WWW-Authenticate: Bearer resource_metadata=…
Metadados do recurso
https://mcp.agateo.com.br/.well-known/oauth-protected-resource/mcp
Authorization server
https://eowxffcgonmbbsohedox.supabase.co/auth/v1
Registro de cliente
Dinâmico (RFC 7591), sem client secret
Escopos
openid email offline_access
Login e consentimento
https://auth.agateo.com.br. A pessoa precisa fazer isso no navegador; não existe chave de API.
Instruções em Markdown
https://auth.agateo.com.br/llms.txt

Depois de conectado, chame tools/list para ver as ferramentas disponíveis. No começo da conversa, chame context_get_summary para saber onde a pessoa parou em qualquer app; salve objetivos, pendências e onde a conversa parou com context_save_note; para algo antigo, use context_search_history. Também existem system_get_status e system_get_current_user. Finanças e agenda estão em construção.

Problemas comuns

O e-mail de confirmação não chegou
Confira a caixa de spam. Na tela de cadastro há um botão para reenviar.
“Esta solicitação de conexão expirou”
O pedido do app vale por pouco tempo. Volte ao app e conecte de novo.
O app pede para conectar de novo
Remova o conector e adicione outra vez. Se continuar, avise a gente.
Quero desconectar um app
Remova o conector nas configurações do próprio app.
